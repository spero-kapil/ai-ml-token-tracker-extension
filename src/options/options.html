Data source

By default the extension reads the usage figures shown on chatgpt.com/settings/usage in your own signed-in browser session. No credentials are stored and no private APIs are called.

Authorized usage endpoint (optional)

Only set this if you have an officially supported or explicitly authorized endpoint that returns your usage as JSON, for example {"plan": "plus", "limits": [{"period": "monthly", "remaining_percent": 72, "reset_at": "2026-11-01T00:00:00Z"}]} or {"weekly": {"remaining_percent": 72, "reset_at": "2026-10-27T09:00:00Z"}}. The background worker fetches it every 15 minutes with your browser's cookies. Leave it empty to disable.

Tracking server

After every refresh the latest usage is sent to <server>/api/chat-gpt. Enter host:port (http:// is assumed) or a full URL. Default: 127.0.0.1:3000.

Error log

Errors are written to the browser console and kept here (last 500). To also write them to logs/error.log in the project directory, run npm run logs in the project folder. Errors logged while it isn't running are written once it starts.
